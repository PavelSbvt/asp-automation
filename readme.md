# asp-automation

Приложение для автоматической сборки протоколов кандидатских экзаменов аспирантов
(автоматизация работы УПиАКВК). 

Поддерживаемые платформы:
* Windows 10/11 (64-bit)

Для работы программы необходимо:
* Python 3.11+
* предустановленный Microsoft Excel
* Подключение к сети Интернет (опционально)

Все команды выполняются в терминале из **корневой папки проекта**.

## Установка

Создайте виртуальное окружение:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Для установки зависимостей выполните:

```bash
pip install -r requirements.txt
```

## Запуск

### Через терминал

Для запуска проекта выполните:

```bash
python src/main.py
```

### Через PyCharm

В проекте есть готовая конфигурация запуска (`.run/main.run.xml`).

1. Откройте проект в PyCharm.
2. В правом верхнем углу выберите конфигурацию `main`.
3. Нажмите **Run** (или `Shift + F10`).

Если не удалось запустить проект через Run в IDE, то в настройках проекта 
`Settings → Python → Interpreter` укажите нужный интерпретатор.

## Сборка

Для сборки проекта через pyinstaller выполните:

```bash
pyinstaller pyinstaller.spec
```

> Собранный проект появится в папке `dist` в корневой папке проекта
>
> Запуск: перейдите в папку `dist/PDF_Maker/` и запустите `PDF_Maker.exe`.
